# hy2-manager

Bash-менеджер VPN-нод: Hysteria2 + VLESS/REALITY, SS-2022, Trojan/WS (Xray), TUIC v5 (sing-box).
Точка входа — `hy2-manager.sh` (TUI-меню), логика в `lib/*.sh`, HTTP API — в `webapi/`.

Список загружаемых модулей — массив `_required_libs` в `hy2-manager.sh` (единственный
источник правды: `install.sh` парсит его же). **Новый `lib/*.sh` без записи в этот
массив не подхватится.**

## Документация

**`docs/README.md` — навигатор.** Начинай поиск по теме с него, а не с обхода
дерева. Четыре папки по степени реальности, у каждой свой `README.md` с таблицей
«документ → о чём → какие файлы кода править»:

| Папка | Что внутри |
|---|---|
| `docs/guide/` | как работает то, что **уже написано** (API, протоколы, онлайн, лимиты, бот, оплаты, эксплуатация) |
| `docs/issues/` | **реестр проблем** `P-NN` по темам: что не работает или работает не так, как обещает документ |
| `docs/design/` | спроектировано, кода нет |
| `docs/research/` | заметки про маркет локаций (`01`…`07`, `11`) — не план работ |

Читай доку темы перед правкой её кода; новая фича = новый документ в
`docs/guide/` + строка в его таблице. Заводишь папку — заводи в ней `README.md`.

## Правила

- **`docs/issues/` — живой реестр нерешённых проблем.** Нашёл проблему (даже
  если чинить не собираешься) — сразу запись в файл своей темы и строка в
  `docs/issues/README.md`. Починил — правь статус там же и не удаляй запись: она
  объясняет, почему код выглядит так.
- После правок в `webapi/` — `systemctl restart hy2-webapi`.
- Тесты: `tests/test-*.sh`, запускаются напрямую bash.
- Индикатор «работает» в UI — 💚, не 🟢.
- Коммит после каждого изменения; пуш пачкой при 7+ коммитах. Не форс-пушить `main`.
- Эта машина — нода **node-a**: webapp/webapi/caddy и все протоколы локальные,
  остальные ноды — отдельные VPS, обновляются с GitHub `main`.
- Необходимо менять версию менеджера каждый комит. 1 комит - меняем третье число версии (это число никогда не обнуляется, оно прибавляется каждый комит). 1 пуш - меняем второе число версии (последнее число не обнуляем при этом). Первое число я меняю
- **Правило версии НЕ действует на коммиты, которые меняют только `docs/`**
  (плюс `README.md`/`CLAUDE.md`): доки не код, версию менеджера они не двигают.
  Тронул хоть один файл кода вместе с доками — версия меняется как обычно.
